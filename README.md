# MyQuiz copy helper
Расширение чтоб быстро копировать вопрос из `myquiz`

## Installation

### Google Chrome (и другие Chromium: Edge, Яндекс Браузер, Opera)
1. Открываем `chrome://extensions`
2. Включаем `Режим разработчика` (переключатель справа сверху)
3. Нажимаем `Загрузить распакованное расширение` и выбираем папку с проектом (где лежит `manifest.json`)

### Firefox (128+)
Открываем `about:debugging#/runtime/this-firefox`, нажимаем `Load Temporary Add-on...` и выбираем `manifest.json`

## Usage
На странице `myquiz.ru` нажимаете `Ctrl + Shift + D` (на macOS тоже именно `Ctrl`, не `Cmd`) — копируется текст вопроса с вариантами ответа. Работает на любой раскладке.

Альтернатива — клик по иконке расширения на панели браузера.

Сменить сочетание клавиш в Chrome: `chrome://extensions/shortcuts`
